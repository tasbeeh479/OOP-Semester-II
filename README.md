## Build & Run (C++)

### Compile a single file
```bash
g++ main.cpp -o app
./app
```

### Compile multiple `.cpp` files (same folder)
```bash
g++ *.cpp -o app
./app
```

> If a topic includes multiple files, compile all required sources together (or use an IDE like VS Code / Code::Blocks).
